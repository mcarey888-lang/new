Add a new section to my Summit Ready app called “Explore Trails”.

Goal:
Create a compact, simple version of an AllTrails-style feature inside the app. It should help users discover local hikes, hills, trails and mountain training routes, without overcomplicating the app.

Important:
Do not replace the existing app or redesign the whole UI. Add this as a separate section in the current navigation.

Main features:

1. Explore Trails homepage
Create a new section called “Explore Trails” with cards for:
- Nearby Trails
- Training Hills
- Saved Routes
- Completed Routes
- Create My Own Route

2. Trail list
Show a list of sample trail cards. Each card should include:
- Trail name
- Location
- Distance
- Elevation gain
- Estimated time
- Difficulty: Easy, Moderate, Hard
- Terrain type: woodland, hill, mountain, coastal, road, mixed
- Best for: training, family walk, summit prep, scenic walk
- Save button
- Start button

3. Trail detail page
When a user taps a trail, show:
- Trail name
- Short description
- Distance
- Elevation gain
- Route type: loop, out-and-back, point-to-point
- Difficulty
- Estimated time
- Terrain
- Weather warning placeholder
- Kit checklist suggestion
- “Start Route” button
- “Save Route” button
- “Mark as Completed” button

4. Map placeholder
Add a simple map area or placeholder for now.
It should say:
“Interactive route map coming soon”
Do not build full GPS navigation yet unless it already exists in the app.

5. Filters
Add basic filters:
- Distance
- Difficulty
- Elevation gain
- Route type
- Best for: summit prep, fitness, family, scenic

6. Search
Add a search bar so users can search trails by name, location or difficulty.

7. Saved routes
Allow users to save routes to a “Saved Routes” list.

8. Completed routes
Allow users to mark a route as completed.
Completed routes should appear in a “Completed Routes” section and update the user’s activity/history if the app already has that feature.

9. Training link
Because this is for Summit Ready, connect each route to mountain preparation.
On each route, show:
- “Good for cardio”
- “Good for elevation training”
- “Good for long endurance”
- “Good for pack weight training”
Use simple badges.

10. Create My Own Route
Add a basic form where users can manually add a route:
- Route name
- Location
- Distance
- Elevation gain
- Estimated time
- Difficulty
- Terrain type
- Notes
Save it into the user’s routes.

Design:
Keep the style consistent with the current Summit Ready app.
Use clean cards, simple icons, rounded corners and mobile-first layout.
Make it feel outdoors/adventure focused but not cluttered.

Data:
For now, use realistic sample trail data.
Structure the code so real trail data, GPS, maps or APIs can be added later.

Do not use copyrighted AllTrails branding, logos, wording or copied content.
This should be inspired by the concept only, but branded fully as Summit Ready.

Technical:
Use the existing app structure, routing, components and styling.
Add reusable components where sensible:
- TrailCard
- TrailDetail
- TrailFilters
- SavedRoutes
- CompletedRoutes
- CreateRouteForm

Make sure it works on mobile and desktop.
Make sure there are no broken routes or console errors.
