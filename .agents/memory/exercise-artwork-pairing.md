Incline Treadmill uses the right-half crop of its own treadmill library image on the session card, but uses the Stepper library image as its session-detail hero. This mismatch was explicitly presented to the user, who approved it before asking for the same cropped-card and selected-exercise-hero approach across the other exercises.

**Why:** The approved pairing is not a filename mistake to silently correct; the user confirmed it after being asked specifically about the Stepper hero for Incline Treadmill.

**How to apply:** Keep that one hero exception when refining exercise imagery. Other exercise cards use their respective library artwork, and their detail heroes should follow the selected exercise. Ask before replacing the approved exception with a treadmill hero.
