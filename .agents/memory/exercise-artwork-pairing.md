name: Exercise artwork pairing
description: Session imagery must match the labelled exercise, including older mismatched sessions.
---

Incline Treadmill uses the right-half crop of its own treadmill library image on the session card and the full treadmill library image on session detail. A previous Stepper-image exception for the detail hero was explicitly reversed by the user after they saw “STAIRMASTER” above “Incline Treadmill.”

**Why:** Although the earlier unusual pairing was approved, the user later identified that the session image was wrong and asked for the incline treadmill image. The newer correction takes precedence.

**How to apply:** Match the artwork to the named exercise across cards and session detail. For a session explicitly labelled Incline Treadmill, show treadmill artwork even if stale exercise metadata says Stepper. Other exercises continue using their matching library artwork.

Exercise artwork on session detail should use the full exercise-library image as a full-width, top-edge hero without outer padding, not a thumbnail or a lettering-free crop behind the title. The user later requested square images flush with the left edge of the Basecamp mission and upcoming session cards, superseding the earlier narrow mission strip.

**Why:** The full-bleed art under a strong scrim looked mostly black, while the lettering-free crop hid the actual artwork. The user identified the intact exercise image previously shown lower in “Where and when” as the exact one wanted in the hero, and asked to remove that section. A subsequent screenshot showed the image inset below the header; the user explicitly wanted it flush to the page's top and side edges. The later Basecamp screenshot prompted the square, left-flush card-image request. The source artwork itself does not need resizing.

**How to apply:** Keep mountain photos as backgrounds where appropriate. Render the full exercise art first, edge-to-edge and at its natural proportions, then the screen header and session details below so controls do not obscure its lettering. On the mission and upcoming cards, keep the image square and flush with the left edge; preserve the text inset and Start action. If reorganizing the detail screen, keep hill, exercise and day controls accessible even though the “Where and when” section is gone.
